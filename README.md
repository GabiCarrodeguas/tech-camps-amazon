## 📖 Sobre o projeto

Um simples toque em um botão de **"Comprar agora"**, se torna uma corrida invisível: servidores na nuvem, algoritmos de inteligência artificial, robôs e rotas de entrega trabalham juntos antes de o pacote chegar à sua porta.

Este site foi desenvolvido para a **EXPO TECH CAMPS 2026** e mostra, de forma visual e interativa, a tecnologia por trás da **Amazon**: da história da empresa aos três pilares que sustentam cada pedido.

> ⚠️ **Projeto educacional independente, desenvolvido por alunos do CAMPS. Não é um site oficial da empresa.**

##  Os três pilares tecnológicos

1. ** E-commerce e IA:** recomendações personalizadas, busca por relevância, previsão de demanda e antifraude.
2. ** Logística e robótica:** robôs da Amazon Robotics (origem na Kiva Systems, 2012), visão computacional e rotas otimizadas.
3. ** Amazon Web Services (AWS):** a espinha dorsal da nuvem, com data centers, virtualização e serviços como EC2 e S3.

---

##  Tecnologias e destaques técnicos

- **HTML5 semântico** com navegação por âncoras e atalho "ir para o conteúdo"
- **CSS3** com variáveis, Grid, Flexbox e animações, sem frameworks
- **JavaScript puro (vanilla)**: menu mobile, animações ao rolar, etapas interativas e simulador
- **Responsivo:** celulares, tablets e desktops
- **Acessível:** foco visível, rótulos ARIA e respeito à preferência de movimento reduzido do sistema
- **Sem dependências:** não precisa instalar nada

## 🚀 Como rodar localmente

**Opção 1: duplo clique**
Abra a pasta e dê dois cliques no `index.html`. Ele abre no navegador.

**Opção 2: VS Code com Live Server (recomendado)**
1. Abra a pasta do projeto no VS Code.
2. Instale a extensão **Live Server** (Ritwick Dey).
3. Clique com o botão direito no `index.html` → **Open with Live Server**.

> 💡 Não execute o `script.js` com Node.js ou com o botão ▶ do Code Runner. Ele precisa de um navegador para funcionar.

**Clonando pelo Git:**
```bash
git clone https://github.com/SEU-USUARIO/tech-camps-amazon.git
cd tech-camps-amazon
```

---

##  Publicação (GitHub Pages)

1. No repositório, vá em **Settings → Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`, e clique em **Save**.
4. Em instantes, o site fica disponível em `https://SEU-USUARIO.github.io/tech-camps-amazon/`.
